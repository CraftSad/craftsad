# Иконки «3D Бирка»

Исходник — `public/favicon.svg`: объёмная садовая бирка с ростком, лесной
зелёный `#203e33`, светлое золото `#e4cf9f` и бронзовый торец `#a57d46`.
Сплошной силуэт сохраняет читаемость в маленькой вкладке браузера.
`public/brand-mark.svg` остаётся отдельным детализированным знаком бренда.

После изменения SVG выполните из корня репозитория:

```sh
bun run icons:generate
```

Скрипт использует Sharp из установленного Next.js. Сначала выполните `bun install`.
Сгенерированные файлы хранятся в Git; генерация при запуске сайта не нужна.

| Файл в `public/` | Назначение |
| --- | --- |
| `favicon.svg` | Основная масштабируемая иконка вкладки |
| `favicon.ico` | Совместимый ICO с кадрами 16, 32 и 48 px |
| `apple-touch-icon.png` | Непрозрачная иконка iOS, 180 × 180 px |
| `icon-192.png` | Иконка манифеста, 192 × 192 px |
| `icon-512.png` | Иконка манифеста, 512 × 512 px |
| `icon-maskable-512.png` | Иконка Android с запасом для системной обрезки |

Подключения браузерных и Apple-иконок находятся в `src/app/layout.tsx`.
Next.js автоматически подключает `src/app/manifest.ts` как `/manifest.webmanifest`.
Цвет манифеста согласован с `viewport.themeColor`. Режим `browser` сохраняет
обычную навигацию сайта; манифест не обещает работу без интернета.
Не добавляйте параллельные `src/app/favicon.ico`, `icon.*` или `apple-icon.*`:
это создаст второй источник метаданных или конфликт маршрута `/favicon.ico`.
